Algori é uma linguagem de programação tipada e de pseudocódigo desenvolvida por Wanfranklin Alves, projetada para ensino de algoritmos e estruturas de dados em língua portuguesa. Com palavras reservadas como mostrar, capturar, se, enquanto e funcao, o Algori permite que estudantes foquem na lógica do algoritmo sem a barreira de sintaxe em inglês. O nome é uma abreviação de algoritmo, reforçando o propósito central da linguagem.

O Algori suporta nove tipos de dados, incluindo inteiro, real, decimal, texto, caractere, logico, vetor, matriz e vazio, com 48 palavras reservadas inteiramente em português. A linguagem também inclui 12 funções nativas para operações matemáticas e manipulação de textos, além de suporte completo a funções com tipo de retorno e parâmetros tipados, permitindo a criação de programas modulares e organizados.

Primeiro Programa

O que é: Todo programa pode opcionalmente começar com a palavra algori seguida de um nome. É como uma assinatura que identifica seu programa.

Para que serve: Declara o início do programa e define seu nome, que é usado para identificar o arquivo e organizar o código.

Como usar: Comece com algori "Nome" seguido do código, ou escreva o código diretamente sem nenhum cabeçalho. O nome deve conter apenas letras, números e underscores.

Algori 
algori "MeuPrograma"

mostrar("Olá, Mundo!")
Dica: O comando mostrar() exibe texto no console. É a forma mais simples de saída de dados.

Variáveis

O que são: Variáveis são "caixas" onde você guarda dados como números, textos ou valores lógicos. Cada variável tem um nome e um tipo.

Para que servem: Permitem armazenar e manipular informações durante a execução do programa, como nomes de usuários, contadores ou cálculos.

Como usar: Declare o tipo antes do nome e opcionalmente atribua um valor. Por exemplo: inteiro idade = 25

Algori 
// Números inteiros
inteiro idade = 25
inteiro ano = 2026

// Números decimais
real pi = 3.14
decimal salario = 3500.00

// Texto
texto nome = "João"
caractere inicial = 'A'

// Booleano
logico ativo = verdadeiro
Tipo Descrição Exemplo
inteiro Números inteiros inteiro x = 10
real Números decimais real pi = 3.14
decimal Alta precisão decimal d = 0.0001
texto Cadeia de caracteres texto t = "oi"
caractere Caractere único caractere c = 'A'
logico Verdadeiro ou falso logico b = verdadeiro
vetor Lista de valores inteiro v[5]
matriz Tabela bidimensional inteiro m[3][3]

Entrada e Saída

O que são: Entrada e saída são as formas de comunicação entre o programa e o usuário. Saída mostra informações, entrada recebe dados.

Para que servem: Permitem que o programa exiba resultados e receba informações do usuário durante a execução, tornando-o interativo.

Como usar: Use mostrar() para exibir texto e capturar() para ler dados do usuário.

Algori 
algori "EntradaSaida"

// Saída de dados
mostrar("Qual é o seu nome? ")

// Entrada de dados
texto nome = ""
capturar(nome)

mostrar("Olá, ", nome, "!")

Condicionais

O que são: Condicionais são estruturas que permitem ao programa tomar decisões com base em condições (verdadeiras ou falsas).

Para que servem: Permitem que o programa execute blocos de código diferentes dependendo de situações específicas, como idade do usuário ou valores calculados.

Como usar: Use se (condição) seguido de um bloco {}. Opcionalmente adicione senao se ou senao.

Algori 
inteiro idade = 20

se (idade >= 18) {
    mostrar("Maior de idade")
} senao se (idade >= 16) {
    mostrar("Pode dirigir")
} senao {
    mostrar("Menor de idade")
}

Repetições

O que são: Repetições (loops) são estruturas que permitem executar um bloco de código várias vezes, enquanto uma condição for atendida.

Para que servem: Evitam a repetição manual de código. São úteis para percorrer listas, contar números ou executar ações repetidamente.

Como usar: Use enquanto (condição) para loops while ou para (início; condição; passo) para loops for.

Algori - Enquanto 
inteiro i = 1
enquanto (i <= 5) {
    mostrar("Contagem: ", i)
    i = i + 1
}
Algori - Para 
// Estilo C
para (inteiro i = 0; i < 5; i = i + 1) {
    mostrar(i)
}

// Estilo legado
para i de 1 ate 5 faca
    mostrar(i)
fimPara

Funções

O que são: Funções são blocos de código reutilizáveis que realizam uma tarefa específica. Elas podem receber dados (parâmetros) e retornar resultados.

Para que servem: Organizam o código, evitam repetição e tornam o programa mais fácil de entender e manter. Funções são como "mini-programas" dentro do programa.

Como usar: Declare com funcao tipo nome(parâmetros) e use retorne para devolver um valor. Chame a função pelo nome.

Algori 
// Função com retorno
funcao inteiro somar(inteiro a, inteiro b) {
    retorne a + b
}

// Função sem retorno
funcao vazio saudar(texto nome) {
    mostrar("Olá, ", nome, "!")
}

// Chamando as funcoes
inteiro resultado = somar(10, 20)
saudar("João")

Estrutura da Linguagem

O que é: A estrutura da linguagem define as regras de como o código deve ser escrito, incluindo sintaxe moderna e legada.

Para que serve: Oferece flexibilidade para programadores vindos de outras linguagens (como Portugol) enquanto mantém uma sintaxe moderna e limpa.

Como usar: Escolha entre a sintaxe moderna (com {}) ou legada (com fimSe, fimPara).

Sintaxe Moderna 
algori "Exemplo"

inteiro x = 10
texto nome = "Algori"

se (x > 5) {
    mostrar("Maior que 5")
}

para (inteiro i = 0; i < x; i = i + 1) {
    mostrar(i)
}
Sintaxe Legada 
programa Exemplo

inteiro x = 10
texto nome = "Algori"

se x > 5 entao
    mostrar("Maior que 5")
fimSe

para i de 0 ate 9 faca
    mostrar(i)
fimPara

Tipos de Dados

O que são: Tipos de dados definem que tipo de informação uma variável pode armazenar, como números inteiros, decimais, textos ou booleanos.

Para que servem: Garantem que os dados sejam tratados corretamente pelo programa, evitando erros como somar texto com números.

Como usar: Sempre declare o tipo antes do nome da variável. Escolha o tipo adequado para cada dado.

Tipo Tamanho Valores Exemplo
inteiro 4 bytes -2.1B a 2.1B 42
real 4 bytes Ponto flutuante 3.14
decimal 8 bytes Alta precisão 0.0001
texto Variant Até 2B chars "Olá"
caractere 1 byte ASCII 'A'
logico 1 byte true/false verdadeiro

Validador de CPF 
algori "ValidadorCPF"

texto cpf = ""
mostrar("Digite o CPF (apenas números): ")
capturar(cpf)

se (tamanho(cpf) != 11) {
    mostrar("CPF inválido!")
} senao {
    inteiro soma = 0
    inteiro i = 0
    
    // Primeiro dígito verificador
    i = 0
    enquanto (i < 9) {
        inteiro d = cpf[i] - "0"
        soma = soma + d * (10 - i)
        i = i + 1
    }
    inteiro resto = soma % 11
    inteiro d1 = se (resto < 2) { 0 } senao { 11 - resto }
    
    // Verificação
    inteiro p = cpf[9] - "0"
    se (p == d1) {
        mostrar("CPF válido!")
    } senao {
        mostrar("CPF inválido!")
    }
}
Sistema de Gerenciamento de Biblioteca

Sistema completo com cadastro, busca, empréstimos e relatórios.

algori "SistemaBiblioteca"

/*
  ============================================
  Sistema de Gerenciamento de Biblioteca
  ============================================
  Autor: Wanfranklin Alves
  Versao: 1.0
  
  Funcionalidades:
  - Cadastro de livros e usuarios
  - Emprestimo e devolucao
  - Busca por titulo, autor e categoria
  - Relatorios e estatisticas
  - Controle de multas
  ============================================
*/

// === ESTRUTURAS DE DADOS ===

// Cadastro de Livros (max 100)
texto titulos[100]
texto autores[100]
texto categorias[100]
inteiro quantidades[100]
inteiro disponiveis[100]
real precos[100]
inteiro totalLivros = 0

// Cadastro de Usuarios (max 50)
inteiro idsUsuarios[50]
texto nomesUsuarios[50]
texto emails[50]
inteiro livrosEmprestados[50]
real multas[50]
inteiro totalUsuarios = 0

// Emprestimos (max 200)
inteiro empLivro[200]
inteiro empUsuario[200]
texto empDataEmprestimo[200]
texto empDataDevolucao[200]
logico empAtivo[200]
inteiro totalEmprestimos = 0

// === FUNCOES AUXILIARES ===

funcao texto formatarData(inteiro dia, inteiro mes, inteiro ano) {
  texto resultado = ""
  se (dia < 10) {
    resultado = resultado + "0"
  }
  resultado = resultado + dia + "/"
  se (mes < 10) {
    resultado = resultado + "0"
  }
  resultado = resultado + mes + "/" + ano
  retorne resultado
}

funcao inteiro buscarLivro(texto tituloBusca) {
  inteiro i = 0
  inteiro resultado = -1
  enquanto (i < totalLivros) {
    se (titulos[i] == tituloBusca) {
      resultado = i
      i = totalLivros
    }
    i = i + 1
  }
  retorne resultado
}

funcao inteiro buscarUsuario(inteiro idBusca) {
  inteiro i = 0
  inteiro resultado = -1
  enquanto (i < totalUsuarios) {
    se (idsUsuarios[i] == idBusca) {
      resultado = i
      i = totalUsuarios
    }
    i = i + 1
  }
  retorne resultado
}

funcao texto obterStatusLivro(inteiro indice) {
  texto resultado = ""
  se (disponiveis[indice] > 0) {
    resultado = "Disponivel (" + disponiveis[indice] + "/" + quantidades[indice] + ")"
  } senao {
    resultado = "Emprestado"
  }
  retorne resultado
}

funcao cadastrarLivro() {
  mostrar("")
  mostrar("=== CADASTRO DE LIVRO ===")
  mostrar("")
  
  texto titulo
  texto autor
  texto categoria
  inteiro quantidade
  real preco
  
  mostrar("Titulo do livro: ")
  capturar(titulo)
  mostrar("Autor: ")
  capturar(autor)
  mostrar("Categoria: ")
  capturar(categoria)
  mostrar("Quantidade de exemplares: ")
  capturar(quantidade)
  mostrar("Preco unitario (R$): ")
  capturar(preco)
  
  se (totalLivros < 100) {
    titulos[totalLivros] = titulo
    autores[totalLivros] = autor
    categorias[totalLivros] = categoria
    quantidades[totalLivros] = quantidade
    disponiveis[totalLivros] = quantidade
    precos[totalLivros] = preco
    totalLivros = totalLivros + 1
    
    mostrar("")
    mostrar("Livro cadastrado com sucesso!")
    mostrar("Total de livros: ", totalLivros)
  } senao {
    mostrar("")
    mostrar("Erro: Limite de livros atingido!")
  }
}

// === FUNCIONALIDADE 2: CADASTRO DE USUARIOS ===

funcao cadastrarUsuario() {
  mostrar("")
  mostrar("=== CADASTRO DE USUARIO ===")
  mostrar("")
  
  inteiro id
  texto nome
  texto email
  
  mostrar("ID do usuario: ")
  capturar(id)
  
  se (buscarUsuario(id) != -1) {
    mostrar("")
    mostrar("Erro: ID ja cadastrado!")
    retorne
  }
  
  mostrar("Nome completo: ")
  capturar(nome)
  mostrar("Email: ")
  capturar(email)
  
  se (totalUsuarios < 50) {
    idsUsuarios[totalUsuarios] = id
    nomesUsuarios[totalUsuarios] = nome
    emails[totalUsuarios] = email
    livrosEmprestados[totalUsuarios] = 0
    multas[totalUsuarios] = 0.0
    totalUsuarios = totalUsuarios + 1
    
    mostrar("")
    mostrar("Usuario cadastrado com sucesso!")
    mostrar("Total de usuarios: ", totalUsuarios)
  } senao {
    mostrar("")
    mostrar("Erro: Limite de usuarios atingido!")
  }
}

// === FUNCIONALIDADE 3: EMPRESTIMO ===

funcao emprestarLivro() {
  mostrar("")
  mostrar("=== EMPRESTIMO DE LIVRO ===")
  mostrar("")
  
  inteiro idUsuario
  texto tituloLivro
  
  mostrar("ID do usuario: ")
  capturar(idUsuario)
  mostrar("Titulo do livro: ")
  capturar(tituloLivro)
  
  inteiro idxUsuario = buscarUsuario(idUsuario)
  inteiro idxLivro = buscarLivro(tituloLivro)
  
  se (idxUsuario == -1) {
    mostrar("")
    mostrar("Erro: Usuario nao encontrado!")
    retorne
  }
  
  se (idxLivro == -1) {
    mostrar("")
    mostrar("Erro: Livro nao encontrado!")
    retorne
  }
  
  se (disponiveis[idxLivro] <= 0) {
    mostrar("")
    mostrar("Erro: Livro indisponivel!")
    retorne
  }
  
  se (livrosEmprestados[idxUsuario] >= 5) {
    mostrar("")
    mostrar("Erro: Usuario ja atingiu o limite de emprestimos!")
    retorne
  }
  
  se (multas[idxUsuario] > 0) {
    mostrar("")
    mostrar("Erro: Usuario possui multas pendentes de R$ ", multas[idxUsuario])
    retorne
  }
  
  se (totalEmprestimos < 200) {
    empLivro[totalEmprestimos] = idxLivro
    empUsuario[totalEmprestimos] = idxUsuario
    empDataEmprestimo[totalEmprestimos] = formatarData(23, 8, 2026)
    empDataDevolucao[totalEmprestimos] = formatarData(6, 9, 2026)
    empAtivo[totalEmprestimos] = verdadeiro
    totalEmprestimos = totalEmprestimos + 1
    
    disponiveis[idxLivro] = disponiveis[idxLivro] - 1
    livrosEmprestados[idxUsuario] = livrosEmprestados[idxUsuario] + 1
    
    mostrar("")
    mostrar("Emprestimo realizado com sucesso!")
    mostrar("Data de devolucao: ", empDataDevolucao[totalEmprestimos - 1])
  } senao {
    mostrar("")
    mostrar("Erro: Limite de emprestimos atingido!")
  }
}

// === FUNCIONALIDADE 4: DEVOLUCAO ===

funcao devolverLivro() {
  mostrar("")
  mostrar("=== DEVOLUCAO DE LIVRO ===")
  mostrar("")
  
  inteiro idUsuario
  texto tituloLivro
  
  mostrar("ID do usuario: ")
  capturar(idUsuario)
  mostrar("Titulo do livro: ")
  capturar(tituloLivro)
  
  inteiro idxUsuario = buscarUsuario(idUsuario)
  inteiro idxLivro = buscarLivro(tituloLivro)
  
  se (idxUsuario == -1) {
    mostrar("")
    mostrar("Erro: Usuario nao encontrado!")
    retorne
  }
  
  se (idxLivro == -1) {
    mostrar("")
    mostrar("Erro: Livro nao encontrado!")
    retorne
  }
  
  inteiro i = 0
  logico encontrado = falso
  enquanto (i < totalEmprestimos && !encontrado) {
    se (empLivro[i] == idxLivro && empUsuario[i] == idxUsuario && empAtivo[i]) {
      empAtivo[i] = falso
      encontrado = verdadeiro
      disponiveis[idxLivro] = disponiveis[idxLivro] + 1
      livrosEmprestados[idxUsuario] = livrosEmprestados[idxUsuario] - 1
      
      mostrar("")
      mostrar("Devolucao realizada com sucesso!")
      mostrar("Livro devolvido: ", titulos[idxLivro])
    }
    i = i + 1
  }
  
  se (!encontrado) {
    mostrar("")
    mostrar("Erro: Emprestimo nao encontrado para este usuario/livro!")
  }
}

funcao buscarLivros() {
  mostrar("")
  mostrar("=== BUSCAR LIVROS ===")
  mostrar("")
  mostrar("1 - Buscar por titulo")
  mostrar("2 - Buscar por autor")
  mostrar("3 - Buscar por categoria")
  mostrar("4 - Listar todos")
  mostrar("")
  mostrar("Opcao: ")
  
  inteiro opcao
  capturar(opcao)
  
  texto termo = ""
  se (opcao != 4) {
    mostrar("Digite o termo de busca: ")
    capturar(termo)
  }
  
  inteiro i = 0
  inteiro encontrados = 0
  
  mostrar("")
  mostrar("--- RESULTADOS ---")
  
  enquanto (i < totalLivros) {
    logico corresponde = falso
    
    se (opcao == 1 && titulos[i] == termo) {
      corresponde = verdadeiro
    }
    se (opcao == 2 && autores[i] == termo) {
      corresponde = verdadeiro
    }
    se (opcao == 3 && categorias[i] == termo) {
      corresponde = verdadeiro
    }
    se (opcao == 4) {
      corresponde = verdadeiro
    }
    
    se (corresponde) {
      mostrar("")
      mostrar("Titulo: ", titulos[i])
      mostrar("Autor: ", autores[i])
      mostrar("Categoria: ", categorias[i])
      mostrar("Status: ", obterStatusLivro(i))
      mostrar("Preco: R$ ", precos[i])
      encontrados = encontrados + 1
    }
    
    i = i + 1
  }
  
  mostrar("")
  mostrar("Total encontrado: ", encontrados, " livro(s)")
}

// === FUNCIONALIDADE 6: RELATORIOS ===

funcao gerarRelatorios() {
  mostrar("")
  mostrar("=== RELATORIOS ===")
  mostrar("")
  mostrar("1 - Livros mais emprestados")
  mostrar("2 - Usuarios com mais emprestimos")
  mostrar("3 - Estatisticas gerais")
  mostrar("4 - Livros por categoria")
  mostrar("")
  mostrar("Opcao: ")
  
  inteiro opcao
  capturar(opcao)
  
  se (opcao == 1) {
    mostrar("")
    mostrar("--- LIVROS POPULARES ---")
    inteiro i = 0
    enquanto (i < totalLivros) {
      inteiro emprestimos = quantidades[i] - disponiveis[i]
      mostrar(titulos[i], " - ", emprestimos, " emprestimo(s)")
      i = i + 1
    }
  }
  
  se (opcao == 2) {
    mostrar("")
    mostrar("--- USUARIOS ATIVOS ---")
    inteiro i = 0
    enquanto (i < totalUsuarios) {
      mostrar(nomesUsuarios[i], " - ", livrosEmprestados[i], " livro(s)")
      i = i + 1
    }
  }
  
  se (opcao == 3) {
    mostrar("")
    mostrar("--- ESTATISTICAS GERAIS ---")
    mostrar("Total de livros: ", totalLivros)
    mostrar("Total de usuarios: ", totalUsuarios)
    mostrar("Total de emprestimos: ", totalEmprestimos)
    
    inteiro emprestimosAtivos = 0
    real valorMultas = 0.0
    inteiro i = 0
    enquanto (i < totalEmprestimos) {
      se (empAtivo[i]) {
        emprestimosAtivos = emprestimosAtivos + 1
      }
      i = i + 1
    }
    i = 0
    enquanto (i < totalUsuarios) {
      valorMultas = valorMultas + multas[i]
      i = i + 1
    }
    
    mostrar("Emprestimos ativos: ", emprestimosAtivos)
    mostrar("Multas pendentes: R$ ", valorMultas)
  }
  
  se (opcao == 4) {
    mostrar("")
    mostrar("--- LIVROS POR CATEGORIA ---")
    texto catAtual = ""
    inteiro i = 0
    enquanto (i < totalLivros) {
      se (categorias[i] != catAtual) {
        catAtual = categorias[i]
        mostrar("")
        mostrar("[", catAtual, "]")
      }
      mostrar("  - ", titulos[i], " (", autores[i], ")")
      i = i + 1
    }
  }
}

Boas Práticas

Seguir boas práticas de programação desde o início ajuda a escrever código mais limpo, legível e fácil de manter. Abaixo estão as principais recomendações para programar em Algori.

1

Use nomes descritivos

Dê nomes significativos às variáveis que expliquem seu propósito.

// Ruim
inteiro x = 10
inteiro t = 365

// Bom
inteiro idade = 10
inteiro diasNoAno = 365
2

Comente o porquê, não o quê

Comentários devem explicar a intenção do código, não a sintaxe.

// Ruim
inteiro i = 0  // inicializa i

// Bom
inteiro i = 0  // índice para percorrer o vetor
3

Use blocos sempre que possível

Prefira a sintaxe moderna com {} em vez da legada.

// Evite (legado)
se x > 10 entao
    mostrar("Maior")
fimSe

// Prefira (moderno)
se (x > 10) {
    mostrar("Maior")
}
4

Declare variáveis no início

Mantenha todas as declarações no topo do programa para melhor organização.

// Bom
inteiro idade
texto nome
real salario

mostrar("Nome: ")
capturar(nome)
mostrar("Idade: ")
capturar(idade)
5

Valide entradas do usuário

Sempre verifique se os valores recebidos são válidos antes de processá-los.

inteiro idade = 0
mostrar("Digite sua idade: ")
capturar(idade)

se (idade >= 0 && idade <= 150) {
    mostrar("Idade: ", idade)
} senao {
    mostrar("Idade invalida!")
}
6

Use funções para reutilizar código

Extraia blocos de código repetidos em funções com tipo de retorno.

// Função reutilizável
funcao real calcularMedia(real n1, real n2, real n3) {
    retorne (n1 + n2 + n3) / 3
}

real m1 = calcularMedia(8, 7, 9)
real m2 = calcularMedia(6, 5, 8)

Limitações

Como toda linguagem em desenvolvimento, o Algori possui algumas limitações que devem ser consideradas. Conhecer essas limitações ajuda a evitar frustrações e a planejar melhor seus programas.

!

Sem importação de bibliotecas

O Algori não suporta importação de bibliotecas externas. Todas as funções disponíveis são as 12 built-in incluídas na linguagem. Não é possível criar módulos ou arquivos separados.

!

Sem ponteiros ou referências

Variáveis são passadas por valor, não por referência. Não é possível manipular endereços de memória ou criar estruturas como listas encadeadas de forma eficiente.

!

Sem tratamento de exceções

Não há mecanismo formal de tratamento de erros (try/catch). Erros de execução interrompem o programa com uma mensagem no console.

!

Acesso ao sistema

O código não tem acesso ao sistema de arquivos, rede ou dispositivos externos. No navegador, a execução ocorre em um Web Worker isolado.

!

Sem orientação a objetos

O Algori é uma linguagem imperativa e estruturada. Não suporta classes, herança, polimorfismo ou outros conceitos de POO.

!

Limite de iterações

Loops são limitados a 10.000 iterações para prevenir travamentos. Recursão é limitada a 50 chamadas. Esses limites podem ser insuficientes para algoritmos complexos.

!

Extensão do arquivo

Arquivos devem ter a extensão .algori. O nome do programa deve conter apenas letras, números e underscores (sem espaços ou caracteres especiais).

Dica: Essas limitações são intencionais para manter a simplicidade da linguagem. O Algori foi projetado para ensinar lógica e algoritmos, não para desenvolvimento profissional. Para projetos mais complexos, considere migrar para uma linguagem de programação completa, como Python, JavaScript, Java ou C#.
