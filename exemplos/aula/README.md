# Exercícios para Aula - Algori

Esta pasta contém exercícios prontos para usar em sala de aula.

## Como Usar

1. Copie o arquivo desejado para a pasta do aluno
2. Execute com: `algori nome_do_arquivo.algori`
3. Siga as instruções na tela

## Dicas para Professores

- Comece pelos exercícios básicos
- Peça para os alunos digitarem o código (não copiar)
- Explique cada linha antes de executar
- Use os exercícios como base para provas
- Incentive os alunos a modificarem os exercícios

## Solução de Problemas

Se um exercício não funcionar:

1. Verifique se está usando palavras-chave em português
2. Verifique se os parênteses e chaves estão corretos
3. Execute `algori --version` para verificar a instalação
4. Consulte o [Guia do Professor](../GUIA_PROFESSOR.md)
